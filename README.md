# iEconomicSystem

iEconomicSystem is a multi-economy plugin for LeviLamina.

> [!WARNING]
> This release is intended for development and testing only. Do not use it in production. APIs, configuration formats, and ABI contracts may change before the first stable release.

## Features

- Multiple pluggable economy systems
- Accounts, balances, transfers, and spending allowances
- Administrative balance, minting, and burning operations
- Multi-economy conversion paths and payment processing
- Transaction history and expression-based search
- Configurable in-game menus
- Versioned LeviLamina services for optional third-party integration
